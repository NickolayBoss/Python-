# Группировка по сигнатуре

[Алгоритмы](README.md) · [Задача 012](../problems/p012_catalog_anagrams/README.md)

Сигнатура — канонический ключ объекта. Для каждого объекта вычисляем ключ и добавляем индекс в список `groups[key]`. Один проход создаёт разбиение на группы, если равенство ключей точно соответствует нужному отношению.

Инвариант: после обработки префикса каждый индекс находится в группе своего ключа. Новый объект либо дополняет такую группу, либо создаёт её. Это доказывает корректность, если отдельно доказана корректность самого ключа.

Словарь Python сохраняет порядок вставки. Если ключ добавляется только при первом появлении, порядок групп соответствует первым появлениям. Добавление индексов при последовательном проходе сохраняет порядок внутри группы.

Стоимость построения ключей включается во время работы. Хеширование кортежа с `k` простыми элементами требует `O(k)`, поэтому выражение «словарь работает за O(1)» не отменяет обработку длинных ключей. Оценка операций поиска предполагает обычное среднее поведение хеш-таблицы.
