# Дейкстра и очередь с приоритетом

[Алгоритмы](README.md) · [Эталон стоимости для задачи 002](../problems/p002_robot_route/baseline_dijkstra.py)

## Назначение

Алгоритм Дейкстры находит кратчайшие пути от одной вершины в графе с **неотрицательными** весами. В отличие от BFS, он выбирает следующую вершину по минимальной предварительной стоимости. Для этой операции удобно использовать бинарную кучу.

В Python модуль `heapq` реализует минимальную кучу: `heappush` добавляет элемент, `heappop` извлекает минимальный. Куча не является полностью отсортированным списком: гарантируется минимальный элемент на вершине и порядок родителей относительно потомков.

## Основные действия

1. Расстояние старта — 0, остальных вершин — бесконечность.
2. Помещаем старт с меткой 0 в кучу.
3. Извлекаем запись с минимальной меткой.
4. Если она устарела, пропускаем её.
5. Иначе проверяем исходящие рёбра и добавляем улучшенные метки.
6. При необходимости только одного ответа останавливаемся на актуальном извлечении цели.

В репозитории приведена реализация с ленивым удалением старых записей: уменьшение ключа заменено добавлением новой записи. Это проще, чем искать элемент внутри кучи.

```python
cost, row, col = heappop(heap)
if cost != distances[row][col]:
    continue
```

При равных стоимостях кортежи сравниваются по следующим полям. Здесь это целые координаты, поэтому сравнение определено. Если второе поле содержит объекты, которые нельзя упорядочить, нужен дополнительный числовой счётчик для разрешения равенств.

## Обоснование

Актуальная извлечённая метка окончательна: любой более дешёвый путь должен был бы пройти через вершину с ещё меньшей меткой, которую очередь обработала бы раньше. Подробный аргумент дан в [главе о 0–1 BFS](04_zero_one_bfs.md); различается структура, обеспечивающая выбор минимума.

При отрицательных рёбрах стоимость продолжения может уменьшить уже пройденный префикс, и этот аргумент перестаёт работать. Поэтому неотрицательность — обязательная предпосылка стандартной Дейкстры.

## Сложность

Для реализации с дубликатами в куче число записей ограничено `O(E+1)`, время — `O(V + (E+1) log(E+2))`, дополнительная память — `O(V+E)`. В простом графе распространена сокращённая запись `O((V+E) log V)`.

Для сетки `E=O(N)`: время **`O(N log(N+1))`**, память **`O(N)`**. Здесь 0–1 BFS использует специальное ограничение весов и убирает логарифмический множитель.

## Роль во второй главе

Дейкстра служит вторым, более общим способом получить минимальную стоимость. Файл `baseline_dijkstra.py` предоставляет функцию `minimum_cost_dijkstra`, а не отдельный интерфейс печати маршрута. Тесты сравнивают стоимости и отдельно проверяют допустимость пути основного решения. Это важно: два правильных алгоритма могут вернуть разные оптимальные маршруты.

Операции кучи описаны в [официальной документации Python 3.10](https://docs.python.org/3.10/library/heapq.html).
