# Границы в отсортированном массиве

[Задача 006](../problems/p006_trip_tariff/README.md) · [Модуль bisect](../python/06_bisect.md)

В отсортированном массиве все элементы меньше `x` стоят перед элементами, которые не меньше `x`. Ищем позицию раздела, включая позицию `len(values)`, если весь массив меньше `x`.

```python
def lower_bound(values, target):
    left, right = 0, len(values)
    while left < right:
        middle = (left + right) // 2
        if values[middle] < target:
            left = middle + 1
        else:
            right = middle
    return left
```

Инвариант. До `left` все элементы меньше цели, начиная с `right` все элементы не меньше цели. Сравнение в середине исключает одну часть интервала благодаря сортировке. Когда границы совпадут, это и будет первая подходящая позиция. Верхняя граница использует условие `values[middle] <= target` для присваивания `left = middle + 1`.

Число сравнений логарифмическое. В решении вместо ручного цикла используется библиотечный `bisect_left`.

В задаче 003 бинарный поиск выбирал допустимое значение ответа. Здесь он ищет позицию в уже отсортированном каталоге. Общий принцип — найти переход монотонного условия.
