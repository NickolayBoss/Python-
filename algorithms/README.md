# Разбор алгоритмов

[На главную](../README.md)

| Материал | Что объясняет | Где применяется |
|---|---|---|
| [BFS](01_bfs.md) | Очередь, посещённость, компоненты | Базовая версия первой задачи |
| [DSU](02_dsu.md) | Представители, объединение, размеры | Поддержка связности при добавлении клеток |
| [Офлайн-запросы](03_offline_queries.md) | Сортировка, монотонность, восстановление порядка | Много порогов без повторных обходов |
| [0–1 BFS](04_zero_one_bfs.md) | Релаксация, два слоя расстояний, устаревшие записи | Путь при весах 0 и 1 |
| [Дейкстра](05_dijkstra.md) | Минимальная куча, окончательные метки | Путь при неотрицательных весах |

BFS и DSU решают разные задачи. BFS перечисляет достижимые вершины и может находить кратчайшие пути в невзвешенном графе. DSU быстро отвечает, находятся ли вершины в одном множестве, и поддерживает объединения; пути между вершинами она не восстанавливает.
