# Проверка скобок стеком

[Каталог алгоритмов](README.md) · [Теория](../theory/08_stack_invariant.md) · [Задача 013](../problems/p013_correct_brackets/README.md)

Для каждого символа слева направо:

1. Открывающую вместе с исходной позицией положить на вершину.
2. Для закрывающей проверить наличие вершины и совпадение типа по словарю `закрывающая → открывающая`.
3. При несовпадении вернуть текущую позицию; при совпадении удалить вершину.

В конце пустой стек означает успех. Если остались открывающие, выбор ответа зависит от условия: в задаче 013 нужна самая ранняя, поэтому берём дно. Проверка закрывающих имеет приоритет над этим ответом.

Для `([)]` после двух символов вершина равна `[`. Следующий `)` требует `(`, значит ответ 3. Нельзя извлечь `(` из середины: такая операция допускает пересечение пар.

Каждая открывающая добавляется и удаляется не более раза: время `O(n)`, память `O(h)`, где `n` — длина, `h` — максимальная глубина. Рекурсия не нужна, поэтому глубокая вложенность не упирается в лимит вызовов Python.
