# Python: Алгоритмическое программирование

**Русскоязычное практическое пособие: от условия задачи до обоснованного и проверенного решения.**

Я собираю здесь задачи, которые помогают понять алгоритмическое мышление: построить модель, выбрать структуру данных, доказать корректность и оценить затраты времени и памяти. Каждый разбор связывает теорию с работающим кодом и показывает, почему выбранный подход подходит именно к этим ограничениям.

Материалы рассчитаны на читателя, знакомого с переменными, условиями и циклами Python. Более сложные конструкции разобраны отдельно. Все решения запускаются на **Python 3.10+**, используют только стандартную библиотеку и не требуют сторонних пакетов.

## Первая глава: связность на сетке

[**001. Аварийная сеть датчиков**](problems/p001_emergency_network/README.md)

На прямоугольном поле размещены датчики с разной устойчивостью к помехам. Для каждого уровня помех нужно найти число работающих сетей и размер крупнейшей. Соседние по стороне работающие датчики соединяются друг с другом.

Разбор начинается с BFS для одного состояния и приводит к обработке множества запросов через сортировку и DSU. В нём есть два независимых решения, пошаговый пример, доказательство корректности и проверка оптимизированного алгоритма на малых переборах.

## Как читать

1. Прочитайте [основы моделирования и сложности](theory/01_foundations.md).
2. Решите базовую версию первой задачи для одного порога.
3. Разберите [BFS](algorithms/01_bfs.md) и сравните его со своим решением.
4. Перейдите к полной версии: почему повторный обход становится дорогим?
5. Изучите [DSU](algorithms/02_dsu.md), затем [офлайн-обработку](algorithms/03_offline_queries.md).
6. Прочитайте [разбор реализации](problems/p001_emergency_network/editorial.md), запустите тесты и выполните упражнения.

## Запуск

Из корня репозитория:

```bash
python --version
python problems/p001_emergency_network/solution.py < problems/p001_emergency_network/examples/01.in
python -m unittest discover -s tests -v
```

В Windows при необходимости используйте `py` вместо `python`. Если оболочка не поддерживает `<` (например, PowerShell), запустите файл без перенаправления, вставьте пример и завершите ввод: `Ctrl+Z`, затем Enter в Windows; `Ctrl+D` в Unix.

Ожидаемый ответ для первого примера:

```text
0 0
2 1
2 2
2 4
1 9
2 1
```

## Как проверяется код

Тесты включают примеры, границы, повторяющиеся пороги, диагональные клетки, слияние сетей, полный перебор 729 сеток 2×3 со значениями 0–2 и 1000 случайных случаев с фиксированным seed. Ответ DSU сравнивается с независимым BFS. Отдельно проверяются запуск из командной строки и поле из 200 000 клеток.

GitHub Actions запускает тот же набор на Python 3.10 и 3.12. Это проверка корректности; тест на большом поле не является гарантией прохождения произвольного лимита времени на конкурсной платформе.
