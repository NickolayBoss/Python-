# Префиксные суммы и разность границ

[Теория](README.md) · [Задача 005](../problems/p005_balance_segments/README.md)

## Определение

Пусть `P[0]=0`, а `P[r]` — сумма первых `r` элементов. Тогда сумма полуоткрытого фрагмента `[l,r)` равна `P[r]-P[l]`. Все элементы до `l` при вычитании сокращаются.

Для `[2,-1,2,1,-2]` префиксы равны `[0,2,1,3,4,2]`. Фрагмент с индексами `[2,4)` имеет сумму `P[4]-P[2]=4-1=3`.

Полный массив префиксов строится за `O(n)` времени и памяти, после чего любой запрос суммы по двум границам занимает `O(1)`. Но для подсчёта всех подходящих фрагментов перебор всех пар всё ещё квадратичен.

## Превращаем сумму в поиск партнёра

Условие `P[r]-P[l]=s` равносильно `P[l]=P[r]-s`. Зафиксировав правую границу, нужно узнать число более ранних префиксов с конкретным значением.

Хранить достаточно не сам массив, а текущую сумму и словарь частот уже обработанных префиксов. Порядок важен: нужны только `l<r`, иначе можно посчитать пустой или обращённый период.

## Роль пустого префикса

`P[0]=0` не обозначает разрешённый пустой период. Это левая граница периодов, которые начинаются с первого элемента. До чтения операций частоты равны `{0:1}`. Без этой записи потеряются все ответы с левой границей 0.

Пустые периоды исключаются другим правилом: сначала запрашиваем частоту партнёра, затем добавляем текущую правую границу в словарь. Особенно заметно это при `s=0`.

## Почему окно из предыдущей главы не переносится

Отрицательные изменения разрушают монотонность суммы. В `[5,-2]` сумма первого элемента больше 3, но сумма всего фрагмента равна 3. Если сдвинуть левую границу сразу после превышения, нужный период будет потерян.

Разность префиксов остаётся точной независимо от знаков. Это пример выбора алгоритма по свойствам задачи, а не по внешнему сходству двух задач о фрагментах.

## Порядок величин

Модуль префикса может достигать `2*10^14`. Количество ответов не больше `n(n+1)/2`: при 200 000 нулей и цели 0 оно равно 20 000 100 000. Python `int` хранит такие значения без фиксированного 32-битного переполнения.
