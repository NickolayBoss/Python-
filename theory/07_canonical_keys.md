# Каноническая форма и классы эквивалентности

[Теория](README.md) · [Задача 012](../problems/p012_catalog_anagrams/README.md)

Чтобы группировать объекты по правилу, найдите функцию `key`, для которой `key(a) == key(b)` тогда и только тогда, когда объекты относятся к одной группе. Необходимо доказать оба направления. Если ключ теряет существенные данные, разные группы ошибочно сольются; если он сохраняет лишний порядок, одна группа разделится.

Для анаграмм существенны символы и их количества, но не позиции. Частотный словарь сохраняет нужные данные. Сортировка его пар устраняет различие в порядке появления символов. Получается канонический ключ.

Множество символов не подходит: у `ab` и `aab` оно одинаковое. Отсортированная строка подходит, хотя сортировать все символы иногда дороже, чем различные символы с частотами.

Аналогичный приём применяется при группировке документов по нормализованным идентификаторам и наборов признаков без учёта порядка. Правила нормализации нужно определить до построения ключа.
