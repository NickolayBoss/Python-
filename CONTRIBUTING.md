# Стандарт материалов

Я оформляю пособие так, чтобы отдельную главу можно было изучить и проверить без переписки с автором.

## Что входит в новую задачу

1. Самостоятельное условие: точная модель, ограничения, ввод, вывод и примеры с объяснениями.
2. Базовая идея и причина перехода к оптимизации.
3. Реализация с осмысленными именами, функцией вычисления и отдельным вводом-выводом.
4. Доказательство через инвариант или другой подходящий аргумент.
5. Сложность с определением переменных и учётом вспомогательной памяти.
6. Граничные тесты; для нетривиальной оптимизации — независимый эталон на малых данных.
7. Ссылки на нужную теорию и конструкции Python, упражнения для закрепления.

## Стиль

Текст — на русском, идентификаторы — на английском в `snake_case`, классы — `PascalCase`. Комментарии объясняют причину действия и ограничения. Не следует заменять аргументы словами «самый умный» или «самый быстрый»: выбор алгоритма обосновывается моделью и ограничениями.

Пути папок — латиницей для удобства командной строки и ссылок. Заголовки материалов — по-русски. Номер задачи постоянен: `p001_emergency_network`. Внутренние ссылки относительные.

При адаптации внешнего условия указывайте источник и характер изменений. Не выдавайте чужие формулировки или решения за собственные. Первая глава развивает исходную модель поиска связных клеток и содержит новую учебную постановку с несколькими порогами.

## Перед добавлением

```bash
python -m unittest discover -s tests -v
```

Проверьте, что примеры согласованы с решением, ссылки ведут к существующим материалам, а текст описывает фактическое поведение кода. Новую тему следует связывать с каталогами главной страницы, алгоритмов и теории.
