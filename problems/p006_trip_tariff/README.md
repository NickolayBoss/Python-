# 006. Тариф для каждой поездки

[Том I](../../volumes/volume_01/README.md) · [Маршрут 001–100](https://github.com/NickolayBoss/Python-/issues/1) · [Разбор](editorial.md) · [Решение](solution.py)

**Темы** — границы бинарного поиска и суффиксный минимум.

## Условие

Сервис предлагает тарифы. У каждого есть предельная дальность `d` и цена `p`. Тариф подходит для поездки длины `x`, если `x <= d`. Тарифы перечислены по неубыванию дальности. Дальности могут повторяться, а цены идут в произвольном порядке.

Для каждой поездки найдите минимальную цену среди подходящих тарифов. Если подходящих тарифов нет, ответ равен `-1`. Поездки независимы.

## Ввод

Первая строка содержит `n q` — число тарифов и поездок. Следующие `n` строк содержат пары `d p`. Последняя строка содержит `q` длин поездок.

- `1 <= n, q <= 200000`
- `1 <= d, x <= 10^9`
- `0 <= p <= 10^9`

## Вывод

Выведите по одному ответу на строку в исходном порядке поездок.

## Пример

Ввод

```text
5 5
3 120
5 150
5 100
8 180
10 130
1 5 6 10 11
```

Вывод

```text
100
100
130
130
-1
```

Для поездки длины 5 тарифы с дальностью 5 подходят. Из двух таких тарифов дешевле вариант за 100. Для длины 6 подходят варианты на 8 и 10, и выгоднее второй, за 130. Дальность 11 превышает все пороги.

[Второй пример](examples/02.in) показывает бесплатный тариф и точное совпадение с порогом. [Ответ](examples/02.out).
