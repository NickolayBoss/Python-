# 007. Два товара на бюджет

[Том I](../../volumes/volume_01/README.md) · [Разбор](editorial.md) · [Решение](solution.py)

В магазине есть `n` товаров. Посчитайте, сколькими способами можно выбрать два разных товара, чтобы их суммарная цена не превышала бюджет `b`. Порядок выбора значения не имеет. Товары с одинаковыми ценами занимают разные позиции и считаются отдельно.

## Ввод и вывод

В первой строке даны `n b`. Во второй строке — `n` целых цен. Выведите одно число — количество пар индексов `i < j`, для которых `prices[i] + prices[j] <= b`.

- `1 <= n <= 200000`
- `0 <= b <= 2 * 10^9`
- `0 <= prices[i] <= 10^9`

## Пример

```text
5 7
4 1 6 3 3
```

Ответ — `7`. Товар за 1 образует четыре пары, два товара за 3 образуют ещё одну пару между собой и по одной с товаром за 4.
