# 003. Очередь рендер-фермы

[Каталог задач](../README.md) · [Разбор](editorial.md) · [Решение](solution.py) · [Перебор для малых данных](baseline_bruteforce.py)

**Темы:** бинарный поиск по ответу, монотонный предикат, жадная проверка, разбиение последовательности.  
**Уровень:** средний.  
**Перед началом:** списки, циклы, функции и целочисленное деление. Знание графов из предыдущих глав не требуется.

## Условие

Студия подготовила очередь из `n` заданий на рендеринг. Время обработки задания `i` равно `a[i]` минутам. Есть `k` одинаковых серверов.

Очередь нужно разделить на **не больше `k` непустых непрерывных блоков**. Каждый блок назначается отдельному серверу. Все серверы начинают одновременно, задания внутри своего блока выполняют последовательно и без пауз. Серверы, которым не достался блок, простаивают.

Нельзя менять порядок заданий, делить одно задание между серверами или выдавать одному серверу несколько раздельных частей очереди. Время передачи данных не учитывается.

Время завершения всей работы — максимальная сумма длительностей среди назначенных блоков. Найдите минимальное возможное значение этого времени. Само разбиение выводить не требуется.

## Входные данные

Первая строка содержит `n k`. Вторая строка содержит `n` целых чисел `a[1] ... a[n]`.

Ограничения:

- `1 <= k <= n <= 200000`;
- `1 <= a[i] <= 10^9`.

Это учебная постановка без привязки к онлайн-судье. Фактические лимиты времени и памяти зависят от платформы. Решение рассчитано на `O(n log(sum(a)))` операций, а не на перебор всех разбиений.

## Выходные данные

Выведите одно целое число — минимальное время завершения всей очереди.

## Пример 1. Два сервера

Ввод:

```text
5 2
7 2 5 10 8
```

Вывод:

```text
18
```

Один оптимальный вариант: `[7, 2, 5] | [10, 8]`. Нагрузки серверов — 14 и 18 минут. Лимит 17 не подходит: при сохранении порядка потребуются как минимум три блока `[7, 2, 5] | [10] | [8]`.

## Пример 2. Одинаковые задания

Ввод:

```text
4 3
5 5 5 5
```

Вывод:

```text
10
```

Четыре задания нельзя выдать трём серверам так, чтобы каждый получил не больше одного. Поэтому хотя бы один сервер потратит 10 минут. Разбиение `[5, 5] | [5] | [5]` достигает этой границы.

## Пример 3. Один сервер

Ввод:

```text
3 1
4 1 6
```

Вывод:

```text
11
```

Сервер получает всю очередь, ответ равен сумме длительностей.

## Почему порядок существенен

Для `[8, 8, 1, 1]` и двух серверов ответ равен 10: `[8] | [8, 1, 1]`. Если переставлять задания, можно получить нагрузки 9 и 9, но такая перестановка запрещена. Сортировка входного списка изменяет задачу.

## Самостоятельная практика

1. Выведите одно оптимальное разбиение после нахождения времени. Нужно ли менять бинарный поиск?
2. Теперь нужно использовать ровно `k` серверов. Изменится ли минимальное время при положительных длительностях?
3. Проверьте массив `[2, 3, 5]` при лимите 5 и двух серверах. Почему сравнение должно быть `>`, а не `>=`?
4. Разрешите задания нулевой длительности. Какие доказательства и оценки сохранятся?
5. Разрешите отрицательные значения в абстрактной задаче о суммах. Найдите пример, где жадная проверка перестаёт работать.
6. Как добавить стоимость запуска `s` для каждого используемого сервера, если она прибавляется к времени обработки его блока?
7. Почему нельзя получить ответ простым округлением `sum(a) / k` вверх?
