# 009. Активные заявки

[Том I](../../volumes/volume_01/README.md) · [Разбор и упражнения](editorial.md) · [Решение](solution.py)

**Массив разностей · префиксные суммы**

## Условие

Для каждого из `m` последовательных слотов с номерами от 0 до `m−1` определите число активных заявок. Заявка `[l, r)` активна в слотах от `l` до `r−1`. Совпадающие заявки учитываются отдельно. Пустая заявка `[l, l)` не занимает слотов.

Первая строка содержит `m n` (1 ≤ m ≤ 200 000, 0 ≤ n ≤ 200 000). Далее идут `n` строк `l r` (0 ≤ l ≤ r ≤ m). Выведите `m` чисел через пробел в порядке слотов.

## Пример

**Ввод**

```text
6 4
0 3
2 5
3 6
4 4
```

**Вывод**

```text
1 1 2 2 2 1
```

В слоте 2 активны первые две заявки, в слоте 3 — вторая и третья.
