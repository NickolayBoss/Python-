**Жадный алгоритм · сортировка интервалов**

## Условие

Из заявок на использование одной мастерской выберите максимальное число встреч. Встреча занимает полуоткрытый интервал `[s, e)`: встреча с началом в момент окончания предыдущей допустима. Каждую заявку можно выбрать один раз.

Первая строка содержит число заявок `n` (0 ≤ n ≤ 200 000). Далее идут `n` строк `s e` (0 ≤ s < e ≤ 10⁹). Выведите максимальное число встреч.

## Пример

**Ввод**

```text
5
0 8
1 3
3 5
5 7
2 6
```

**Вывод**

```text
3
```

Можно последовательно провести встречи [1, 3), [3, 5) и [5, 7).
