## Выбор по ближайшему окончанию

Сортируем встречи по моменту окончания. Берём очередную встречу, если она начинается в момент последнего принятого окончания или позже.

| Встреча | Действие |
|---|---|
| [1, 3) | Берём первой |
| [3, 5) | Берём, начало совпадает с предыдущим окончанием |
| [2, 6) | Пропускаем, начало раньше 5 |
| [5, 7) | Берём, начало совпадает с предыдущим окончанием |
| [0, 8) | Пропускаем, начало раньше 7 |

## Доказательство обменом

Среди ещё доступных встреч пусть A заканчивается раньше всех. Возьмём первое занятие B из оптимального расписания для оставшегося времени. Можно заменить B на A: A начинается в доступное время и заканчивается не позже B, поэтому все последующие занятия по-прежнему помещаются. Следовательно, существует оптимум с первым выбором A. Повторяем аргумент после каждого выбора.

Сортировка требует `O(n log n)` времени и `O(n)` дополнительной памяти. Проход по списку занимает `O(n)`.
