# 005. Баланс за период

**Том I · задача 5 из 10.** [Оглавление тома](../../volumes/volume_01/README.md) · [Задачи](../README.md) · [Разбор](editorial.md) · [Код](solution.py)

**Темы:** префиксные суммы, частоты префиксов, подсчёт пар, потоковая обработка.  
**Уровень:** средний. Перед началом полезно изучить словари из задачи 004.

## Условие

Система хранит журнал из `n` изменений баланса. Положительное число означает поступление, отрицательное — списание, ноль — отсутствие изменения. Аналитик ищет все непрерывные непустые периоды журнала, за которые суммарное изменение равно заданному числу `s`.

Найдите количество таких периодов. Периоды различаются границами, даже если их содержимое совпадает. Они могут пересекаться. Переставлять операции или пропускать операции внутри периода нельзя. Начальный баланс и его абсолютное значение не учитываются: анализируется только сумма изменений.

## Ввод

Первая строка содержит `n s`. Вторая — `n` целых чисел `a[i]`.

- `1 <= n <= 200000`;
- `-10^9 <= a[i] <= 10^9`;
- `-10^14 <= s <= 10^14`.

Постановка учебная, без фиксированного лимита онлайн-судьи.

## Вывод

Одно целое число — количество непустых непрерывных периодов с суммой `s`. Перечислять границы не требуется.

## Пример 1

```text
5 3
2 -1 2 1 -2
```

Ответ:

```text
2
```

Подходят позиции 1–3 (`2-1+2=3`) и 3–4 (`2+1=3`), в нумерации с единицы.

## Пример 2: одинаковые значения, разные периоды

```text
4 0
0 0 0 0
```

Ответ:

```text
10
```

Подходят все периоды: четыре длины 1, три длины 2, два длины 3 и один длины 4. Пустой период не считается.

## Пример 3: отрицательная цель

```text
3 -2
-1 -1 2
```

Ответ:

```text
1
```

Подходит только период из первых двух операций.

## Упражнения

1. Найдите один подходящий период и выведите его границы.
2. Найдите самый длинный подходящий период. Что хранить вместо частоты?
3. Найдите самый короткий подходящий период. Как изменится сохранение индекса?
4. Посчитайте периоды с суммой, кратной положительному `m`.
5. Объясните, почему перестановка операций обычно меняет ответ.
6. Можно ли хранить только множество ранее встреченных сумм?

Подсказки — в конце разбора.
