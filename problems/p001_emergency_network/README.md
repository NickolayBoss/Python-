# 001. Аварийная сеть датчиков

[Каталог задач](../README.md) · [Разбор](editorial.md) · [Основное решение](solution.py) · [Базовое решение](baseline_bfs.py)

**Темы:** неявный граф, компоненты связности, BFS, DSU, офлайн-запросы.  
**Уровень:** BFS — базовый; полная версия — продвинутый.

## Условие

В промышленном комплексе установлены датчики на прямоугольном поле из `n` строк и `m` столбцов. Число `a[i][j]` — устойчивость датчика к электромагнитным помехам.

При уровне помех `t` датчик работает тогда и только тогда, когда `a[i][j] >= t`. Два работающих датчика могут напрямую передавать данные, если их клетки имеют общую сторону. Диагональная связь отсутствует.

Работающая сеть — максимальная непустая группа датчиков, между любыми двумя из которых можно пройти по цепочке работающих соседей. Одиночный работающий датчик тоже образует сеть.

Для каждого из `q` независимых сценариев определите:

1. Число работающих сетей.
2. Число датчиков в крупнейшей сети.

Если работающих датчиков нет, оба числа равны нулю. Сценарии не меняют исходные значения устойчивости. Пороги могут повторяться и поступать в любом порядке.

## Входные данные

Первая строка содержит `n m q`. Следующие `n` строк содержат по `m` целых чисел — матрицу устойчивости. Далее записаны `q` порогов `t`, по одному на строке.

Ограничения для полной версии:

- `1 <= n, m`, `n * m <= 200000`;
- `1 <= q <= 200000`;
- `0 <= a[i][j] <= 10^9`;
- `0 <= t <= 10^9 + 1`.

Лимиты времени и памяти зависят от проверяющей платформы; здесь задана учебная постановка без привязки к конкретному онлайн-судье. Для первых экспериментов используйте маленькие поля и один запрос.

## Выходные данные

Для каждого сценария выведите строку `c s`, где `c` — количество сетей, `s` — размер крупнейшей сети. Порядок строк должен совпадать с исходным порядком сценариев.

## Пример 1

Ввод:

```text
3 4 6
9 2 8 1
7 3 6 4
0 5 5 4
10
8
6
5
3
8
```

Вывод:

```text
0 0
2 1
2 2
2 4
1 9
2 1
```

При `t = 8` работают только датчики 9 и 8: они не соседствуют, ответ `2 1`. При `t = 6` образуются две сети `{9, 7}` и `{8, 6}`, ответ `2 2`. При `t = 5` два датчика с устойчивостью 5 присоединяются к правой сети: остаются две сети размеров 2 и 4. При `t = 3` добавляются датчик 3 и два датчика 4: все девять работающих датчиков связаны. Повторный запрос 8 даёт тот же ответ, хотя стоит после меньшего порога.

## Пример 2: диагонали

Ввод:

```text
2 2 3
5 0
0 5
5
6
0
```

Вывод:

```text
2 1
0 0
1 4
```

При пороге 5 диагональные датчики остаются разными сетями. При пороге 0 работают все четыре датчика.

## Что изменилось относительно поиска крупнейшего острова

Вместо высот и воды используются устойчивость и помехи. Главная алгоритмическая перемена — много порогов и два показателя для каждого. Для одного порога достаточно BFS за `O(nm)`. Для полной версии нужен способ переиспользовать вычисления между сценариями.

## Самостоятельная практика

1. Реализуйте BFS для одного запроса без просмотра кода.
2. Добавьте подсчёт количества сетей. Объясните, почему счётчик увеличивается перед новым обходом.
3. Найдите пример, где при снижении порога число сетей сначала растёт, а потом уменьшается.
4. Измените соседство: разрешите диагонали. Какие части решения и тесты потребуют изменения?
5. Добавьте сумму значений устойчивости в каждой компоненте и максимум такой суммы. Продумайте агрегат DSU.
6. Можно ли применить эту же DSU напрямую, если значения датчиков меняются между запросами? Объясните, какая предпосылка перестаёт выполняться.

Подсказки к вопросам 3–6 находятся в конце [разбора](editorial.md).
