# 011. Нормализация названий

[Том II](../../volumes/volume_02/README.md) · [Предыдущая задача](../p010_log_summary/README.md) · [Разбор](editorial.md) · [Решение](solution.py)

**Базовая задача** · Строки, пробельные символы, сравнение без учёта регистра

## Условие

В каталог дважды внесли название. Определите, совпадают ли две записи после нормализации.

1. Удалите пробельные символы с обоих краёв.
2. Замените каждую внутреннюю последовательность пробельных символов одним обычным пробелом U+0020. Используйте правила `str.split()` без аргумента. Пробельными считаются, например, табуляция и неразрывный пробел U+00A0.
3. Примените `str.casefold()` для сравнения без учёта регистра. Это преобразование может менять длину строки, например `ß` превращается в `ss`.

Сравните полученные строки посимвольно. Дефисы и другие знаки препинания сохраняются. Последовательности кодовых точек сравниваются после указанных преобразований, поэтому `é` и `e\u0301` различаются. Пустая строка и строка из одних пробельных символов нормализуются в пустую строку.

## Ввод и вывод

Во входе две строки в UTF-8, по одному названию в каждой. Длина каждого названия от 0 до 200 000 кодовых точек, без учёта перевода строки. Переводы строк разделяют записи. Каждое из двух названий может быть пустым.

Выведите `YES`, если нормализованные названия равны, иначе `NO`.

## Примеры

В таблице использована запись строк Python. Кавычки и обозначения вроде `\t` показывают содержимое строк и в файлах ввода заменены соответствующими символами.

| Первое название | Второе название | Ответ | Объяснение |
|---|---|---|---|
| `"  Северный\tВЕТЕР"` | `"северный ветер"` | `YES` | Убираем пробелы по краям, заменяем табуляцию пробелом и выравниваем регистр |
| `"Straße"` | `"STRASSE"` | `YES` | Оба названия превращаются в `"strasse"` |
| `"Северо-Запад"` | `"Северо Запад"` | `NO` | Дефис сохраняется |
| `""` | `"\t\u00a0"` | `YES` | Обе строки становятся пустыми |
