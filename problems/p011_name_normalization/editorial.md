## Нормализация перед сравнением

Прямое сравнение исходных строк учитывает каждый символ. Для каталога сначала построим строку, в которой допустимые различия в пробелах и регистре уже устранены.

```python
def normalize_name(name: str) -> str:
    return " ".join(name.split()).casefold()
```

Для строки `"  Straße\tNORD  "` вызов `split()` даёт `["Straße", "NORD"]`. Вызов `" ".join(...)` собирает `"Straße NORD"`, а `casefold()` преобразует её в `"strasse nord"`. Результат можно сравнить через `==`.

## Корректность

1. Вызов `split()` без аргумента выделяет все максимальные участки непробельных символов в порядке появления. Пробелы по краям и длина внутренних пробельных участков исчезают из представления. Если таких участков нет, результатом будет пустой список.
2. Вызов `" ".join(...)` сохраняет все участки и вставляет один обычный пробел между соседними. При пустом списке результатом будет пустая строка. Так выполняются оба правила обработки пробельных символов.
3. Вызов `casefold()` применяет указанное в условии преобразование регистра к результату. Следовательно, функция возвращает именно требуемую нормализованную строку. Сравнение двух результатов даёт `YES` тогда и только тогда, когда совпадают названия по правилам задачи.

Читаем каждую строку через `sys.stdin.buffer.readline()` и декодируем её как UTF-8. Перевод строки попадает в конец значения. Вызов `split()` убирает его вместе с остальными краевыми пробельными символами.

## Сложность

Пусть `n` и `m` — длины исходных названий в кодовых точках. Разбиение и склейка линейны, а преобразование одной кодовой точки в `casefold()` имеет ограниченную длину для используемой версии Unicode. Сравнение просматривает максимум линейное число символов. Итог — O(n + m) по времени и O(n + m) по дополнительной памяти на список фрагментов и промежуточные строки.

## Упражнения

1. Подберите строку, для которой `split(" ")` и `split()` дают разные списки. Проверьте повторяющиеся пробелы и табуляцию.
2. Сравните поведение `lower()` и `casefold()` на паре `"Straße"` и `"STRASSE"`. Объясните, почему сравнение после `lower()` даёт другой результат.
3. Предскажите ответы для пар `("A B", "AB")`, `("А-Б", "а-б")` и `("é", "e\u0301")`. Сверьте их с программой.
4. Используйте результат `normalize_name` как ключ словаря и подсчитайте число записей для каждого названия в каталоге.
