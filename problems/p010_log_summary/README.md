# 010. Сводка по журналу

[Том I](../../volumes/volume_01/README.md) · [Разбор](editorial.md) · [Решение](solution.py)

**Итоговая задача тома I** · Префиксные суммы, бинарный поиск, скользящее окно

## Условие

В журнале каждая запись имеет код события и знаковое значение. Обработайте запросы трёх типов. Записи пронумерованы с нуля. Диапазоны полуоткрытые.

| Запрос | Что вывести |
|---|---|
| `1 l r` | Сумму значений записей на `[l, r)` |
| `2 l r c` | Число записей с кодом `c` на `[l, r)` |
| `3` | Длину самого длинного фрагмента всего журнала с не более чем `k` разными кодами |

Первая строка содержит `n q k`. Затем идут `n` строк с парами «код значение» и `q` строк запросов. Выведите ответ на каждый запрос в отдельной строке.

- `1 ≤ n, q ≤ 200 000`, `0 ≤ k ≤ n`.
- `0 ≤ l ≤ r ≤ n`.
- Коды — целые от 0 до 10⁹. Значения — целые от −10⁹ до 10⁹.
- Пустой диапазон даёт 0. При `k = 0` третий запрос тоже даёт 0.

## Пример

| Запрос | Ответ | Объяснение |
|---|---:|---|
| `1 0 3` | 10 | 5 − 3 + 8 |
| `2 1 6 4` | 1 | Код 4 встречается на позиции 2 |
| `3` | 3 | Подходит фрагмент с кодами 4, 2, 4 |
| `1 2 2` | 0 | Пустой диапазон |
| `2 0 6 9` | 0 | Код 9 отсутствует |
| `1 3 6` | 3 | 1 − 4 + 6 |
