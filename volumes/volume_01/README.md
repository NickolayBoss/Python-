## Как работать с томом

1. Прочитайте условие и попробуйте построить модель самостоятельно.
2. Реализуйте простой способ на малых данных.
3. Сравните его с эффективным алгоритмом и разберите доказательство.
4. Изучите используемые конструкции Python.
5. Запустите тесты, затем выполните упражнения без просмотра подсказок.

Нумерация задаёт порядок глав, но задачи 003–005 можно изучать до продвинутого раздела DSU, если пока нужны упражнения с последовательностями. Сложность каждой главы указана в её условии.

## Проверка понимания после задачи 005

- Можете ли вы объяснить, почему DSU не ищет кратчайший путь?
- Чем монотонность предиката отличается от корректности жадной проверки?
- Почему вложенный цикл с двумя указателями может быть линейным?
- Почему отрицательные числа мешают простому окну по сумме?
- Зачем в частотах префиксов нужна начальная запись нуля?

Для запуска всех опубликованных проверок из корня: `python -m unittest discover -s tests -v`.
