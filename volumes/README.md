# Тома пособия

[На главную](../README.md)

Каждый том содержит **10 задач**. Номера задач сквозные: том I — 001–010, том II — 011–020 и далее. Алгоритмы, базовая теория и Python остаются общими справочными разделами, а оглавление тома задаёт порядок изучения.

| Том | Диапазон | Содержание | Готовность |
|---|---|---|---|
| [I. Базовые модели и эффективная обработка данных](volume_01/README.md) | 001–010 | Графы, поиск по ответу, фрагменты и префиксы | 5 из 10 задач опубликованы |

Новый том будет открыт после завершения десяти задач текущего. Планируемые главы не выдаются за готовые. Файлы уже опубликованных задач сохраняют прежние пути, чтобы не ломать ссылки.
