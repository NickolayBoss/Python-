# Python: одноразовый проход и счётчики

[Python](README.md) · [Задача 005](../problems/p005_balance_segments/README.md)

## Iterable и Sequence

`count_segments` принимает `Iterable[int]`: список, кортеж, генератор или другой источник целых чисел, который можно пройти циклом. В отличие от `Sequence`, такой источник не обязан поддерживать длину и индексацию.

```python
changes = (next(numbers) for _ in range(count))
answer = count_segments(changes, target)
```

Круглые скобки создают генератор, который выдаёт значения по запросу. Повторный проход по уже исчерпанному генератору не вернёт прежние элементы. В этой задаче хватает одного прохода; в задаче 003 бинарный поиск многократно обращался ко входу, поэтому там был нужен сохранённый список.

Генератор над `data.split()` не делает весь ввод потоковым: `read()` уже загрузил файл, а `split()` создал токены. Вычислительная функция умеет работать с потоком, но конкурсная обёртка по-прежнему использует `O(n)` памяти.

## Два обращения к get

```python
answer += frequencies.get(prefix - target, 0)
frequencies[prefix] = frequencies.get(prefix, 0) + 1
```

Первое обращение ищет партнёров и не создаёт ключ при отсутствии. Второе получает старый счётчик текущего префикса, после чего присваивание увеличивает его. Ключи — суммы префиксов, а не типы событий из предыдущей главы.

Ключи здесь не удаляются: все предыдущие границы могут пригодиться дальше. В скользящем окне старые элементы покидали состояние; здесь история намеренно накапливается.

## Инициализация и int

`prefix = answer = 0` присваивает обеим переменным неизменяемое целое значение. Последующее `prefix += change` не меняет `answer`: переменная привязывается к новому значению.

Python поддерживает длинные целые, поэтому большие суммы и количество периодов вычисляются точно. Использовать `float` не нужно: задача целочисленная, а вещественное представление может потерять точность при дальнейших расширениях ограничений.

## Проверки через преобразование входа

`reversed(data)` обходит список с конца. Число фрагментов заданной суммы сохраняется при полном развороте: каждому исходному периоду соответствует обращённый период с той же суммой.

Генератор `(-x for x in data)` меняет знаки. Если одновременно заменить цель на противоположную, число ответов тоже сохранится. Такие свойства дополняют сравнение с эталоном, но не заменяют доказательство.
