# Counter, sorted и tuple в ключах словаря

[Python](README.md) · [Задача 012](../problems/p012_catalog_anagrams/README.md)

```python
from collections import Counter

counts = Counter("baba")  # {'b': 2, 'a': 2}
key = tuple(sorted(counts.items()))  # (('a', 2), ('b', 2))
```

`Counter` считает вхождения. Метод `.items()` даёт пары символов и количеств. `sorted` приводит пары к одинаковому порядку независимо от порядка символов в строке. `tuple` создаёт неизменяемую последовательность. Пары внутри тоже являются кортежами, а их элементы — строки и целые числа; такой вложенный ключ хешируемый.

Сам `Counter` и список от `sorted` не являются допустимыми ключами. Кортеж, содержащий список, также не станет хешируемым только благодаря внешнему `tuple`.

```python
groups = {}
for index, name in enumerate(["ab", "aa", "ba"], start=1):
    key = tuple(sorted(Counter(name).items()))
    if key not in groups:
        groups[key] = []
    groups[key].append(index)
# list(groups.values()) == [[1, 3], [2]]
```

Словарь сохраняет порядок вставки ключей. Хеш помогает найти кандидата, затем проверяется равенство: совпадение хешей разных ключей не означает объединение групп.

Для пустой строки `Counter` пуст, и ключ равен `()`. Чтение через `.split()` без аргументов уничтожит пустые записи и пробелы. В задаче 012 читаются отдельные строки с удалением только перевода строки.
