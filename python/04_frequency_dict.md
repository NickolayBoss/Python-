# Python: частотный словарь

[Python](README.md) · [Задача 004](../problems/p004_event_window/README.md)

## dict и get

```python
counts: dict[int, int] = {}
counts[event] = counts.get(event, 0) + 1
```

Ключ — тип события, значение — число его появлений в окне. `get(event, 0)` возвращает текущее значение либо 0 при отсутствии ключа. Сам вызов `get` отсутствующий ключ не создаёт: это делает присваивание.

Чтение `counts[event]` без проверки вызывает `KeyError`, если ключа нет. При удалении слева ключ гарантированно существует: элемент сейчас принадлежит окну.

## Удаление ключа

```python
counts[removed] -= 1
if counts[removed] == 0:
    del counts[removed]
```

`len(counts)` считает ключи, а не сумму частот. Если оставить `{1:0, 2:3}`, длина словаря равна 2, хотя в окне только один тип. Именно поэтому нулевые ключи удаляются.

Словарь изменяется внутри прохода по `events`, а не внутри итерации по самому словарю: запрет изменения размера словаря при обходе его ключей здесь не затрагивается.

## enumerate

```python
for right, event in enumerate(events):
    ...
```

Получаем индекс с нуля и элемент одновременно. `enumerate` выдаёт пары постепенно, не создаёт список всех пар. Правый индекс в этом цикле включительный; сохранённая граница ответа `right+1` — исключительная.

## Границы без копирования

Функция возвращает `(left, right)` для `[left,right)`. Выражение `events[left:right]` создаёт копию среза списка, поэтому внутри каждого шага окно не копируем. Храним только два индекса и частоты.

Для ответа с единицы и включительными концами печатаем `left+1` и `right`. Например, `[3,8)` с нуля соответствует позициям 4–8. Пустой интервал обрабатываем отдельно: условие требует `0 0`.

## Почему не Counter без дополнительных действий

`collections.Counter` удобен для частот, но вычитание до нуля само по себе не удаляет ключ. Если использовать `len(counter)` как число типов, ключи с нулевой частотой всё равно нужно удалять. Обычный `dict` явно показывает нужное правило и не требует дополнительных методов.
