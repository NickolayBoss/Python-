## Два конца deque

В первой главе очередь использовалась как FIFO. Теперь задействуются оба конца:

```python
queue.appendleft((cost, cell))  # слева: продолжение того же слоя
queue.append((cost, cell))      # справа: следующий слой
cost, cell = queue.popleft()
```

`appendleft` не сортирует очередь и не сравнивает стоимости. Порядок гарантирует алгоритм: слева добавляются только улучшения веса 0, справа — веса 1. Просто заменить `append` на `appendleft` в обычном обходе недостаточно, чтобы получить правильный алгоритм кратчайшего пути.

## Строки как строки поля

```python
grid = ["RRD", "ULL"]
cell_symbol = grid[0][1]  # 'R'
```

Строка индексируется по символам. Для чтения поля преобразовывать каждую строку в список не требуется: программа не меняет указатели. Строки Python неизменяемы, поэтому выражение `grid[0][1] = "U"` недопустимо.

## bool в числовом выражении

```python
weight = int(grid[row][col] != direction)
```

Сравнение возвращает `True` или `False`; `int` преобразует их в 1 и 0. Это компактная запись правила стоимости. В эталоне используется `cost + (symbol != direction)`: `bool` является подклассом `int`, поэтому такое сложение допустимо. Явное `int(...)` в основном решении подчёркивает смысл веса для читателя.

## Строгое улучшение и continue

```python
if current_distance != distance[cell]:
    continue
```

`continue` начинает следующую итерацию ближайшего цикла. Здесь это главный цикл извлечений: устаревшая запись не доходит до обработки соседей. Внутри цикла направлений другой `continue` пропускает только текущего соседа, например стену.

Сравнение `candidate < distance[neighbor]` намеренно строгое. Замена на `<=` будет бесконечно добавлять равные расстояния при нулевом цикле.

## heapq

```python
from heapq import heappop, heappush

heap = []
heappush(heap, (4, 2, 3))
heappush(heap, (1, 5, 6))
cost, row, col = heappop(heap)  # (1, 5, 6)
```

`heappush` и `heappop` поддерживают кучу внутри обычного списка. Не вызывайте `heap.sort()` перед каждым извлечением: это лишняя работа. Не вызывайте `heap.pop(0)` вместо `heappop`: обычное удаление первого элемента не восстанавливает инвариант кучи.

Кортежи сравниваются лексикографически: сначала первые элементы, затем вторые при равенстве и так далее. Поэтому `(1, 100, 0) < (2, 0, 0)`: приоритет стоимости важнее координат.

## Восстановление пути: append и reverse

```python
path = []
while cell != -1:
    path.append(divmod(cell, cols))
    cell = parent[cell]
path.reverse()
```

Предшественники ведут от цели к старту. Добавляем элементы в конец списка, затем разворачиваем один раз. `list.reverse()` меняет список на месте и возвращает `None`. Поэтому `path = path.reverse()` уничтожит ссылку на готовый список, записав `None`.

Разворот стоит `O(k)` для `k` клеток. Постоянное `insert(0, ...)` тоже дало бы правильный порядок, но многократно сдвигало элементы, суммарно вплоть до `O(k²)`.

## zip для проверки соседних клеток

```python
for (r, c), (nr, nc) in zip(path, path[1:]):
    ...
```

`zip` объединяет последовательности по позициям. Здесь получаем пары «текущая клетка, следующая клетка». Сам `zip` ленивый, но срез `path[1:]` создаёт дополнительный список. В тестах это достаточно просто; альтернатива на Python 3.10+ — `itertools.pairwise(path)`, без среза. В основном решении такой проход не нужен: стоимость уже вычислена.

## Координаты и формат ответа

Ввод нумеруется с единицы, а индексы Python — с нуля. Преобразуйте координаты один раз при чтении и один раз при печати:

```python
start = (input_row - 1, input_col - 1)
line = f"{row + 1} {col + 1}"
```

Функция `find_route` возвращает пару `(cost, path)`, где `path` — список пар координат. Аннотация `tuple[int, list[tuple[int, int]]]` описывает именно эту структуру, а не три независимых значения.

`lines.extend(...)` добавляет несколько строк к списку; `"\n".join(lines)` собирает один текст с переводами строк. Для недостижимой цели возвращается только `-1`, без фиктивного количества клеток.

## Конечная и настоящая бесконечность

В основной программе `infinity = count + 1`, поскольку доказана верхняя граница возможного конечного ответа. В Дейкстре используется `from math import inf`. Это положительная бесконечность типа `float`; сравнивать с ней целые расстояния можно, а `inf + 1` остаётся `inf`.
