# Python и модуль bisect

[Задача 006](../problems/p006_trip_tariff/README.md) · [Документация Python](https://docs.python.org/3.10/library/bisect.html)

`bisect_left(a, x)` возвращает индекс первого элемента `>= x`, `bisect_right(a, x)` — первого элемента `> x`. Если нужного элемента нет, обе функции для своих условий возвращают `len(a)`. Входной список должен быть отсортирован.

| Дальности | Цель | bisect_left | bisect_right |
|---|---|---|---|
| [3, 5, 5, 8, 10] | 2 | 0 | 0 |
| [3, 5, 5, 8, 10] | 5 | 1 | 3 |
| [3, 5, 5, 8, 10] | 11 | 5 | 5 |

Разность правой и левой границ даёт число точных совпадений. Чтобы получить первый подходящий элемент, сначала проверьте, что индекс меньше длины. Чтобы получить последний элемент `<= x`, используйте `bisect_right(a,x)-1` и проверьте, что индекс не отрицателен. В Python индекс `-1` обращается к последнему элементу.

В основном решении пределы дальности и цены извлекаются распаковкой пар. Это позволяет искать по отдельному списку чисел. Обратный `range(n-2,-1,-1)` начинает со второго индекса с конца и заканчивает на нуле. Эталон использует `min(генератор, default=-1)`, чтобы получить заданный ответ для пустого набора подходящих цен.
