## Матрицы и независимые строки

```python
visited = [[False] * cols for _ in range(rows)]
```

На каждой итерации создаётся новый список-строка. Конструкция `[[False] * cols] * rows` повторяет ссылки на один список: изменение одной строки неожиданно меняет остальные. Внутреннее `[False] * cols` безопасно для значений `bool`, поскольку они неизменяемы.

```python
grid = [list(map(int, input().split())) for _ in range(rows)]
```

`split()` делит строку по пробельным символам, `map(int, ...)` преобразует элементы в числа, `list(...)` материализует строку матрицы. В полном решении ввод разобран единым потоком чисел, чтобы не зависеть от размещения порогов по строкам.

## Очередь

```python
from collections import deque
queue = deque([(row, col)])
r, c = queue.popleft()
queue.append((nr, nc))
```

Кортеж `(row, col)` хранит одну пару координат. Внешний список в `deque([(row, col)])` задаёт последовательность из **одного** элемента. `deque((row, col))` создал бы очередь из двух отдельных чисел. Распаковка `r, c` получает две координаты извлечённой клетки.

## Одномерный номер клетки

Формула `cell = row * cols + col` сопоставляет каждой клетке уникальное число от 0 до `rows*cols-1`. Обратное преобразование:

```python
row, col = divmod(cell, cols)
```

`divmod` возвращает частное и остаток целочисленного деления. Для четырёх столбцов клетка `(2, 1)` имеет номер 9; `divmod(9, 4)` вернёт `(2, 1)`. Соседство обязательно проверяется по координатам: номера 3 и 4 последовательны, но при четырёх столбцах лежат в разных строках.

## Сортировка индексов

```python
queries = sorted(range(len(thresholds)), key=thresholds.__getitem__, reverse=True)
```

`range` задаёт исходные индексы, `key` сообщает значение для сравнения, `reverse=True` включает убывание. Выражение `thresholds.__getitem__` здесь эквивалентно функции `lambda index: thresholds[index]`.

Для порогов `[8, 3, 8]` получится порядок индексов `[0, 2, 1]`. После обработки запрос с индексом `query` сохраняется в `answers[query]`. Поэтому вывод остаётся в исходном порядке. Устойчивость сортировки Python сохраняет порядок равных ключей, но корректность решения от этого не зависит.

## Списки, кортежи и ссылки

```python
answers = [(0, 0)] * count
```

Повторное использование одного кортежа безопасно: кортеж неизменяем, а программа заменяет `answers[index]` целиком. Если бы внутри стояли изменяемые списки и код менял их содержимое, возникла бы та же проблема общих ссылок, что с матрицей.

Списковое включение `[value for row in grid for value in row]` обходит сначала строки, затем элементы каждой строки. Это разворачивает матрицу в порядок по строкам.

## Класс DSU и аннотации

`self` — конкретный экземпляр структуры. У него свои `parent`, `size`, `components`, `largest`. Методы изменяют состояние этого экземпляра. Класс нужен, чтобы связанное состояние и правила его изменения были собраны в одном месте.

`Sequence[Sequence[int]]` означает последовательность последовательностей целых чисел, например список списков или кортеж кортежей. `list[tuple[int, int]]` описывает список пар целых чисел. Аннотации помогают читателю и средствам анализа; Python сам не проверяет их при каждом вызове.

## Ввод и граница памяти

```python
numbers = iter(map(int, data.split()))
rows, cols, count = next(numbers), next(numbers), next(numbers)
```

`data` — байты из `sys.stdin.buffer.read()`. `split()` создаёт список токенов, `map` преобразует их лениво, `next` получает следующий элемент. Это удобно для конкурсного корректного ввода. Программа не является валидатором произвольных файлов: неверное количество чисел приведёт к исключению, а лишние токены отдельно не проверяются.

Чтение целого файла и разбиение на токены увеличивают фактическое потребление памяти. Для жёстких лимитов можно перейти на построчный ввод и более компактные массивы. Асимптотика остаётся линейной по объёму входа; Python-объекты имеют заметные накладные расходы.
