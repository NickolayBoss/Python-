# list.append, list.pop и dict для стека

[Каталог Python](README.md) · [Задача 013](../problems/p013_correct_brackets/README.md)

Обычный список подходит для стека, если вершина находится в конце:

```python
stack: list[tuple[str, int]] = []
stack.append(('(', 1))
bracket, position = stack[-1]  # просмотр без удаления
bracket, position = stack.pop()  # удаление и возврат вершины
```

`append` изменяет список на месте и возвращает `None`. Нельзя писать `stack = stack.append(...)`. Стоимость добавления амортизированно `O(1)`: отдельное расширение списка может копировать элементы, но суммарно серия добавлений линейна. `pop()` с конца имеет стоимость `O(1)`, а `pop(0)` сдвигает оставшиеся элементы за `O(len(stack))` и реализует другой порядок.

Перед `stack[-1]` и `stack.pop()` нужно убедиться, что стек не пуст. Условие `not stack or ...` безопасно: `or` не вычисляет правую часть, если левая истинна.

```python
matching_open = {')': '(', ']': '[', '}': '{'}
```

Словарь связывает каждый закрывающий тип с открывающим. `matching_open[bracket]` вызывается только в ветке закрывающей: по предусловию других символов нет. Если расширить алфавит, эту ветку надо уточнить, иначе возможен `KeyError`.

`enumerate(sequence, start=1)` сразу даёт позиции из условия. Кортеж хранит символ и его позицию вместе. После прохода `stack[0][1]` извлекает позицию со дна без удаления; это `O(1)`.

Функция вычисления возвращает `int | None` (синтаксис Python 3.10+). `None` обозначает отсутствие ошибки. CLI отдельно заменяет его словом `Success`. Пустая строка ввода — байты `b"\n"`; отсутствие ввода — `b""`, это разные случаи. Разделитель CRLF удаляется целиком; скобки сохраняются без изменений.
